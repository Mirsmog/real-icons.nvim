# Third-party notices

`real-icons.nvim` can install and use external icon packs. Installed packs keep
their upstream license and are stored in the user's Neovim data directory.

## Material Icon Theme

- Project: https://github.com/material-extensions/vscode-material-icon-theme
- Package: https://www.npmjs.com/package/material-icon-theme
- License: MIT
- Use in this project: optional icon pack installed by `:RealIcons install`
  and shown in `media/preview-material.png`
